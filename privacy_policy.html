Политика конфиденциальности

Приложение «АлгеШаг» · Android

1. Общие положения

Приложение «АлгеШаг» — калькулятор по алгебре для 6–9 классов. Оно работает полностью офлайн: решение выражений выполняется на устройстве, без обращения к серверам.

2. Какие данные хранятся на устройстве

  • История решённых примеров (выражение, ответ, шаги решения, дата) — в локальной базе данных приложения.
  • Настройки приложения (тема, фон, размер шрифта, вибрация, звук) — в локальном хранилище.
  • Выбранное фото для фона — путь к файлу в галерее устройства.

Все данные хранятся только на вашем устройстве и не передаются третьим лицам.

3. Разрешения приложения

Приложение запрашивает минимально необходимые разрешения:

  • Вибрация (VIBRATE) — тактильный отклик клавиш. Выдаётся автоматически, без запроса.
  • Доступ к изображениям (READ_MEDIA_IMAGES на Android 13+; READ_EXTERNAL_STORAGE на Android 8–12) — только для выбора своего фото в качестве фона калькулятора. На современных Android используется системный выбор фото, и отдельного запроса не требуется.
  • Запись во внешнее хранилище (WRITE_EXTERNAL_STORAGE) — только на Android 8–9, для вложения скриншота в письмо поддержки.

Почему при установке не появляется запрос разрешений: на Android 6.0+ опасные разрешения запрашиваются в момент использования функции, а не при установке. Приложение не использует интернет в рабочей версии.

4. Что происходит при отправке обратной связи

Если вы нажимаете «Сообщить об ошибке / Предложить идею», форма может приложить: версию приложения, модель устройства, версию ОС, скриншот экрана и последнее введённое выражение. Эти данные отправляются только по выбранному вами каналу (Email, Telegram или VK) и только после вашего явного действия.

5. Какие данные НЕ собираются

Приложение не собирает и не передаёт: имя, номер телефона, геолокацию, контакты, содержимое переписки, данные о других приложениях. Реклама и аналитика не используются.

6. Как удалить данные

Историю можно очистить в Настройках → «Данные» → «Очистить историю». Полное удаление приложения удаляет и все его локальные данные.
